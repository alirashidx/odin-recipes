# Odin Recipes 🍽️

A simple recipe website built entirely with **HTML** as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## 📖 About the Project

This project is a beginner-friendly HTML exercise created to practice the fundamentals of building web pages from scratch.

The website contains **three different recipes**, each with its own ingredients, instructions, and images. The entire project was built using **raw HTML**, without CSS or JavaScript.

This project was created with guidance and inspiration from **The Odin Project's Recipes project**.

## 🍳 Recipes

The website includes three different recipes.
Recipe 1 : Skillet Chicken Bulgari
Recipe 2 : One-Pan Shrimp And Rice
Recipe 3 : Pork Medallions with Balsamic Vinegar and Capers

Each recipe page includes:

* A recipe title
* A food image
* A description
* A list of ingredients
* Step-by-step cooking instructions

## 🛠️ Technologies Used

* **HTML5**
* No CSS
* No JavaScript
* No frameworks or libraries

## 🎯 What I Practiced

Through this project, I practiced the fundamentals of HTML, including:

* HTML document structure
* Headings and paragraphs
* Links and navigation
* Images and `alt` attributes
* Ordered and unordered lists
* Structuring content with semantic HTML
* Connecting multiple HTML pages together
